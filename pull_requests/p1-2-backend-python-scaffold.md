# P1.2 — backend-python scaffold (FastAPI)

**Branch:** `2026-05-24-BE-PY/p1-2-backend-python-scaffold`
**Base:** `main`
**Date:** 2026-05-24
**Type:** BE-PY (Python backend only; no contract change beyond defining `/health`)

## Summary

Scaffolds the FastAPI backend under `backend-python/`: an `app` package
(settings, DB wiring, schemas, app factory), the canonical `GET /health`
endpoint, and an initialized Alembic environment wired to app settings. No ORM
models yet (schema lands in P2.1). `/health` is intentionally DB-independent so
it stays byte-identical across both backends. backend-ts and contracts/ are
untouched here (NestJS mirror is P1.3; parity harness is P1.4).

## Canonical /health contract (P1.3 NestJS must mirror exactly)

- `GET /health` → HTTP **200**
- JSON body **exactly** `{"status": "ok"}`
- `content-type: application/json`
- Typed via Pydantic `HealthResponse(status: str)`, so it appears in
  `/openapi.json`. **Does not touch the database.**

## Changes

- **`backend-python/app/__init__.py`** — package marker.
- **`backend-python/app/config.py`** — `Settings` (pydantic-settings v2).
  Fields `app_name` (default `personal-finance-api`) and `database_url`
  (default `postgresql://pf:pf@localhost:5432/personal_finance`). Loads the
  repo-root `.env` if present; defaults work without it. Cached `get_settings()`.
- **`backend-python/app/db.py`** — SQLAlchemy 2.0 `engine`, `SessionLocal`,
  declarative `Base`, and `get_db()` FastAPI dependency. `_normalize_url()`
  rewrites `postgresql://` → `postgresql+psycopg://` (psycopg v3 is the
  installed driver).
- **`backend-python/app/schemas.py`** — `HealthResponse` Pydantic model.
- **`backend-python/app/main.py`** — `create_app()` + module-level `app`,
  CORS for Vite origins (`http://localhost:5173`, `http://127.0.0.1:5173`),
  and `GET /health` returning `HealthResponse(status="ok")` with status 200.
- **`backend-python/alembic/` + `alembic.ini`** — `alembic init`. `env.py`
  resolves `sqlalchemy.url` from `app.config.get_settings()` (normalized to
  psycopg3) and sets `target_metadata = app.db.Base.metadata` (empty for now).
  No URL/secrets hardcoded in `alembic.ini`. `versions/` empty (kept via
  `.gitkeep`).
- **`backend-python/pyproject.toml`** — added `pythonpath = ["."]` to
  `[tool.pytest.ini_options]` so the non-installed `app` package imports under
  pytest (`[tool.uv] package = false`).
- **`backend-python/uv.lock`** — generated by `uv sync` (resolved deps).
- **`backend-python/tests/`** — `conftest.py` (`TestClient(app)` fixture,
  no live DB/network), `test_health.py`, `test_config.py`, `test_db.py`.
- **`plans/agent_checklist.md`** — P1.2 checked off.
- **`docs/STRUCTURE.md`** — dated CHANGELOG line + `backend-python/` subtree.
